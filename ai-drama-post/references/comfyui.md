# 接入已有 ComfyUI

使用本地运行实例。先运行 `studio.py queue --url http://127.0.0.1:8188`；离线只代表服务不可达，不代表模型损坏。不需要生成时无需重启。

需要生成时查询 `/object_info` 核实节点，以及 `/system_stats` 核实设备；导出当前安装可运行的 API 工作流，不捏造模型/节点名。模型路径、精度、显存卸载和插件版本是环境配置，不写死在 skill 中。8GB 显存适合先低分辨率短镜头验证，不承诺整集速度或高分辨率实时生成。

提交前保存工作流 JSON、输入文件指纹、种子和输出前缀。只对用户授权的本地实例 `POST /prompt`，记录返回 prompt_id；恢复时查 `/queue` 与 `/history/{prompt_id}`，核对输出实际存在和可解码。运行中的任务不重复提交，不自动调用 `/interrupt` 或删除队列。网络请求设置超时；断线先读日志再决定重试，单次连接失败不是重生成依据。

skill 不附带大型模型和社区节点，也不预设其许可证。若需安装，按项目约束使用官方来源，先检查现有安装；没有联网授权就提供缺失列表，不能偷偷换付费云服务。
