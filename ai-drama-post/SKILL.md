# AI 漫剧后期工作站

以可追溯镜头计划组织制作。先读取现有剧本、人物设定、素材及用户反馈；保留已选音色和人物身份。先查已有产物与运行任务，避免从头制作或重复提交。

## 路由

- 接手或规划：读 [制作流程](references/production.md)，建立问题清单和新版本计划。缺少会改变剧情、角色或输出的关键信息才询问；常规技术选择自行推进。
- 本地生成：读 [ComfyUI 接入](references/comfyui.md)。检查当前节点、模型、队列和现有工作流；不把任意机器上的工作流假设为通用。
- 计划、审核、基础导出：读 [计划格式](references/plan-format.md)，使用 `scripts/studio.py`。运行 `--help` 获取接口。

## 核心判断

1. 表情、头眼和口型是一个表演整体。优先音频驱动的整体视频生成；已有局部口型方案若破坏身份，诊断并换方案，不反复贴嘴。内心独白不要求开口。静态道具插入可以用，不能把静态人物推拉包装成生成表演。
2. 对齐配音、镜头和停顿。音轨波形相同只证明声音未变速，不证明口型正确。长静音仍张口时，可采用符合空间与人物关系的动态反应镜头，不能遮住问题后宣称精确对嘴。
3. 审查视线、服装、空间、手、道具方向、背景文字和重复镜头；身份介绍的完整粒子入出区间必须落在对应人物画面，不能跨切镜错标。
4. 为生成失败设置有限重试（默认最多两次同类修复）；同一缺陷反复出现就改变方法、缩短单镜头或报告限制。不得停止不属于本任务的进程，不自动清空队列。
5. 冻结已审核文件指纹；文件修改后重新审核。区分技术验证、视觉采样、连续帧检查、真实整段听审。工具不能感知的内容记录为未检查，不自行补勾；只有用户明确接受未完成项才能降级交付，并保留说明。
6. 新版本输出，原片与旧版不覆盖。外部服务、付费和上传遵循用户授权；本地许可不等同外部模型或声音许可。不要把用户私人路径、角色参考或成片放进公开技能包。

## 实施与交付

先小样验证人物身份、声画和显存，再扩展整集。定稿配音后再生成表演；剪辑锁定后制作字幕、人物介绍及最终混音。使用 `doctor` 和 `queue` 只读诊断；`check` 校验计划；完成真实审核后用 `review` 记录；`gate` 失败时修正具体项。

`render` 只提供已审核顺序镜头 + 已完成混音 + ASS 字幕的基础导出。需要更复杂剪辑/特效时采用项目现有 Resolve、ComfyUI 或其他本地管线，保留其可编辑计划；不要声称辅助脚本拥有未实现功能。无混音输入时保留镜头原声。

最终完整解码，核对时长、分辨率、实际编码帧率、声音和字幕；还要真实审阅最终时间线和混音。先前镜头审核不能替代最终听审。报告补帧覆盖范围和放大分辨率，提供成片、预览、审核证据链接及未解决限制。未满足用户要求时标为待审候选，不能称最终成片。
